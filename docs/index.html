How this course works

1 · Read and try

Lessons mix explanation with runnable Python cells that use fleetlab, a small helper library that checks agent files, builds hook payloads, and reads transcripts. It runs in your browser and never calls a model.

2 · Practice

Graded exercises in every module check your code in the page. Hints are there when you need them, and a reference answer for the small in-page exercises.

3 · Build in labs

Each module ends with labs you do on your machine: pixi run start m02-lab1, write the agent or hook, then pixi run grade m02-lab1.

4 · No answer key

Labs ship without solutions. Their checks are the specification. The repository's own CI proves every untouched starter fails, so a green grade means you built it.

5 · Run it for real

Most checks are deterministic and need no API key. Optional live checks (pixi run grade-live <lab>) run your agents with the real claude CLI.

6 · One codebase

Every lab works on shelf, a tiny book-tracking CLI with real bugs, open issues (one of them hostile), and tests.

Stage 1 is available now: the harness, writing a subagent, context engineering, and hooks. Stage 2 (handoffs, orchestration in code, CI, self-healing, and evals) and the capstone are next on the roadmap.

All local work uses Pixi. From the repository root: pixi install once, pixi run serve to open this site, pixi run labs to list labs, pixi run start <lab> to copy a starter into work/, and pixi run grade <lab> to check it.

This course assumes you can read Python and use git. It builds on the Agentic Systems Practicum, which teaches the agent loop from the Messages API up. You don't need it first, but its M09 (the agent loop) is the best background for M01 here.
