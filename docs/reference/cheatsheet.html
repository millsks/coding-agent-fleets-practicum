Agent and Hook Cheat Sheet

The facts you reach for while writing agents and hooks. Check the Claude Code documentation against your installed version before relying on a field.

Subagent file

---
name: reviewer                      # required; matches the file name
description: What it does. Use when…  # required; drives delegation
tools: Read, Grep, Glob, Bash       # omit = inherit everything
disallowedTools: Edit, Write        # removed from the list
model: sonnet                       # sonnet | opus | haiku | fable | full id | inherit
maxTurns: 25                        # always set a budget
isolation: worktree                 # for agents that edit
permissionMode: plan                # default | acceptEdits | plan | auto | dontAsk | bypassPermissions
---
Role and boundary. Inputs. Process. Output format. Stop conditions.

Locations: .claude/agents/ (project), ~/.claude/agents/ (user). Priority: managed > --agents > project > user > plugin. Other fields: effort, skills, mcpServers, hooks, memory, background, omitClaudeMd, autoCompactWindow, initialPrompt, color.

Hooks

Exit codeEffect
0Continue; stdout read as a decision only if it's exactly one JSON object
2Block (on blocking events); stderr is the reason Claude sees
otherNon-blocking error; the action goes ahead. exit 1 does not block
 
// PreToolUse decision (exit 0)
{"hookSpecificOutput": {"hookEventName": "PreToolUse", "permissionDecision": "deny", "permissionDecisionReason": "…"}}
// Stop decision (exit 0)
{"decision": "block", "reason": "…"}
  • Payload (stdin): session_id, transcript_path, cwd, permission_mode, hook_event_name; PreToolUse adds tool_name, tool_input, tool_use_id; Stop adds stop_hook_active, last_assistant_message.
  • Matchers: empty or * = all; Edit|Write = exact list; other characters = regex (mcp__github__.*).
  • Paths: $CLAUDE_PROJECT_DIR. Default command timeout: 600 seconds.
  • Where: user, project, local, managed settings; plugins; skill and subagent frontmatter (Stop → SubagentStop).

Permissions

  • Modes: default, acceptEdits, plan, auto, dontAsk, bypassPermissions.
  • Rules: permissions.allow / ask / deny; deny wins. Bash(git diff *) = prefix followed by a space.
  • Settings precedence for one value: managed > command line > local > project > user. Hook lists combine.

Headless

claude --bare -p "task" \
  --allowedTools "Read,Grep,Glob,Bash(python -m pytest *)" \
  --permission-mode dontAsk --max-turns 20 \
  --output-format json            # or stream-json --verbose
# --json-schema '{...}' → .structured_output   --resume <id> / --continue
# --agents '{...}' (bare mode)   --settings <file>   --append-system-prompt "…"

Result fields: type, subtype, is_error, num_turns, total_cost_usd, session_id, result.

Context

  • CLAUDE.md: ~/.claude/CLAUDE.md, project root, subdirectories; @file imports. Pattern: CLAUDE.md contains @AGENTS.md.
  • Skills: .claude/skills/<name>/SKILL.md, name = folder; metadata always, body when used, linked files when read.
  • Fact → AGENTS.md. Procedure → skill. Guarantee → hook (+ CI).
