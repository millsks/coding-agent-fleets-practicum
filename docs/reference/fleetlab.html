fleetlab Reference

fleetlab is the small helper library used in lesson cells and lab checks. It has no dependencies and never calls a model. In the browser it loads automatically when a cell imports it; locally it is installed in the Pixi environment.

Frontmatter

fleetlab.parse(text) -> Document
Split a Markdown file into .meta (a dict of frontmatter fields) and .body. Handles key: value, comma-separated and [a, b] lists, booleans, integers, quotes, and comments. Raises fleetlab.FrontmatterError for missing delimiters, malformed lines, or repeated keys.

Subagents

fleetlab.check_agent(text, filename=None) -> AgentSpec
Parse and check a subagent definition. spec.problems lists every problem: missing name or description, a name that doesn't match the file, unknown fields, unknown tools or models, bad permissionMode, isolation, effort, or maxTurns, and an empty body.
AgentSpec
.meta, .prompt, .problems, .name, .tools (the effective allowlist after disallowedTools, or None when tools are inherited), and .can_write() (true if it has an edit tool or Bash, or inherits tools).
fleetlab.load_agent(path)
Read and check a file from disk.
KNOWN_FIELDS, KNOWN_TOOLS, READ_ONLY_TOOLS, WRITE_TOOLS
The sets used by the checks.

Skills

fleetlab.check_skill(text, directory_name) -> list[str]
Check a SKILL.md: name present, valid (lowercase, digits, single hyphens, at most 64 characters), and equal to its folder; description present and at most 1,024 characters; only Agent Skills fields; a non-empty body under 500 lines.

Hooks

fleetlab.pre_tool_use(tool_name, tool_input=None, *, cwd=..., permission_mode="default", session_id=...)
The payload Claude Code sends to a PreToolUse hook, as a dict.
fleetlab.stop(*, active=False, last_message="Done.", cwd=..., session_id=...)
The payload for a Stop hook; active sets stop_hook_active.
fleetlab.run_hook(main, payload) -> HookResult
Run a hook's main() in-process with the payload on stdin; captures stdout, stderr, and the exit code from sys.exit. An uncaught exception becomes exit 1, as in a real hook.
fleetlab.run_script(path, payload, *, cwd=None, env=None, timeout=60) -> HookResult
Run a hook file as a subprocess (.py with Python, .sh with bash). A hang returns exit 124.
HookResult
.exit_code, .stdout, .stderr, .json (stdout as one JSON object or None), .decision ("block", "deny", "allow", "ask", or None), .blocked, and .reason.

Settings

fleetlab.matcher_matches(matcher, tool_name) -> bool
Claude Code's matcher rules: empty or * matches all; plain names and |/comma lists match exactly; anything else is an unanchored regular expression.
fleetlab.hook_commands(settings, event, tool_name=None) -> list[str]
The command hooks that would run for an event (and tool).

Transcripts

fleetlab.parse_stream(text) -> Run
Parse claude -p --output-format stream-json --verbose output. Skips lines that aren't JSON objects.
Run
.session_id, .model, .tools, .calls (list of ToolCall), .texts (main-conversation text), .result (the final event), .finished, .succeeded, .num_turns, .cost_usd, and .calls_by_tool().
ToolCall
.id, .name, .input, .parent (the parent_tool_use_id, None for the main conversation), .result, and .is_error.

Context

fleetlab.estimate_tokens(text) -> int
About four characters per token. For budgeting, never for billing.
