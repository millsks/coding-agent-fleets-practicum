Reference · Vocabulary

Glossary

Terms used in the course, with a link to where each is taught.

Terms

Agent
A language model running in a loop with tools, deciding step by step what to do next. Taught in M00
Agent loop
Request, tool calls, results, repeat until the model stops asking for tools. In Claude Code: gather, act, verify. Taught in M01
AGENTS.md
An open, cross-tool file of instructions for coding agents. Import it from CLAUDE.md with @AGENTS.md. Taught in M03
Bare mode (--bare)
A headless run that loads nothing it isn't told about: no hooks, skills, subagents, MCP servers, or CLAUDE.md. Taught in M01
Builder harness
The harness the agent product ships with: its system prompt, tools, loop, and permission system. Taught in M00
CLAUDE.md
Project instructions Claude Code loads at startup from your home directory, the project, and subdirectories. Taught in M03
Compaction
Summarising earlier turns when a long run nears the context limit. Details fade. Taught in M03
Context window
Everything the model sees on a request. Fixed size, paid for on every request. Taught in M03
Doom loop
An agent repeating the same failing action. Shows as identical failing calls in a row. Taught in M01
Drift
An agent changing things the task didn't ask for. Taught in M01
Exit code 2
The hook exit code that blocks an action on blocking events; stderr becomes the reason. Taught in M04
Fleet
Several narrow agents covering the SDLC as stations, passing work through files and guarded by gates. Taught in M00
Gate
A check that must pass before work moves on, enforced by code (a hook, CI) or a person. Taught in M04
Guide
Part of the harness that steers the agent before it acts: instructions, tool limits, specs. Taught in M00
Harness
Everything in an agent except the model: instructions, tools, permissions, checks, and the loop. Taught in M00
Harness engineering
Treating each agent mistake as a missing guide or sensor, and adding it. Taught in M00
Headless mode
Running Claude Code non-interactively with claude -p, for scripts and CI. Taught in M01
Hook
A command Claude Code runs at a fixed point in the loop; some can block. Taught in M04
Least privilege
Giving each agent only the tools and permissions its job needs. Taught in M02
Matcher
The filter on a hook group: exact names, a | list, or a regular expression. Taught in M04
Permission mode
The baseline for which tool calls need approval: default, acceptEdits, plan, auto, dontAsk, bypassPermissions. Taught in M01
Permission rule
An allow, ask, or deny entry such as Bash(git diff *). Deny wins. Taught in M01
Premature done
An agent finishing without verifying its work, such as no test run after the last edit. Taught in M01
Progressive disclosure
Loading a skill in levels: metadata always, body when used, linked files when read. Taught in M03
Prompt injection
Instructions hidden in content an agent reads, such as an issue or web page. Taught in M00
Sensor
Part of the harness that checks the agent's work: tests, hooks, reviewers, CI. Taught in M00
Skill
A folder with a SKILL.md that teaches an agent one procedure, in the open Agent Skills format. Taught in M03
Station
One stage of a fleet: a trigger, an agent, a handoff, and a gate. Taught in M00
stop_hook_active
Stop payload field that is true when the agent is already continuing because a Stop hook blocked it. Taught in M04
stream-json
Headless output format with one JSON event per line, ending in a result event. Taught in M01
Subagent
A separate agent with its own context, prompt, and tools that returns a summary to its caller. Taught in M02
Turn
One request to the model and its response. Taught in M01
User harness
The harness you write: AGENTS.md, agents, skills, hooks, tests, CI. Taught in M00
Worktree
A separate git checkout of the same repository; isolation: worktree runs an agent in one. Taught in M02
