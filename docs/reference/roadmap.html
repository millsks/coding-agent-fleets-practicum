Reference · Roadmap

Roadmap

Level 1 takes you from one agent to a small working fleet. Stage 1 (one agent) is available now. Stage 2 and the capstone come next, then two further levels for running fleets at scale.

Level 1 · Builder

Stage 1 · One Agent (available)

  • M00 How This Practicum Works
  • M01 The Harness: the loop, tools, permissions, settings, headless runs, transcripts
  • M02 Writing a Subagent: definitions, descriptions, prompts, least privilege
  • M03 Context Engineering: AGENTS.md, CLAUDE.md, skills, the context budget
  • M04 Hooks and Gates: guards on risky commands and a Stop gate

Stage 2 · Many Agents (next)

  • M05 Handoffs and Delegation: specs as contracts, subagents versus agent teams, worktrees, one writer per file, and passing work through files a human can review.
  • M06 Orchestrating in Code: driving stations from Python with the Agent SDK and claude -p; structured output with --json-schema; retries, budgets, and state you own. Labs grade your orchestrator against a fake claude binary that replays recorded runs.
  • M07 The Fleet in CI: GitHub Actions triggers, labels as a state machine, anthropics/claude-code-action, secrets, concurrency, timeouts, and running the same fleet under Copilot and Devin through AGENTS.md, skills, and per-tool adapters.
  • M08 Self-Healing Loops: a healer for red CI with attempt caps, no-progress detection, cost limits, classification of failures, and escalation to a human.
  • M09 Evals and Learning: replaying past tasks against harness changes, telemetry with OpenTelemetry, a retrospective agent that proposes evidence-backed harness changes, and deleting rules that no longer earn their place.

Capstone 1 · A Small Fleet

Build triage → plan → build → review for shelf, driven by your own orchestrator, gated by your hooks, and measured against an evaluation set of the five shelf issues.

Levels 2 and 3

  • Level 2 · Fleet operations: running fleets across many repositories, shared harness packages, cost and quality dashboards, incident handling for agent mistakes, and governance in regulated environments.
  • Level 3 · Fleet platform: hosting agents on your own infrastructure, sandboxing and network policy, MCP servers for internal systems, and designing tools for agents.
